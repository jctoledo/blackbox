# Triage roles

These labels describe next action; existing `bug`, `enhancement` and `r&d` labels remain topic/type labels.

| Label | Meaning |
| --- | --- |
| needs-triage | Scope, evidence or next action has not been assessed |
| needs-info | A specific missing fact is required; record it explicitly |
| ready-for-agent | Scope, test seam, acceptance and dependencies are sufficient for autonomous software work |
| ready-for-human | Hardware evidence, account action or a genuinely unresolved maintainer decision is required |
| wontfix | Explicitly declined with a recorded reason |

Use one next-action role at a time. Labels organize work; they do not supply authorization, prove correctness or replace review. A research task can have useful agent work even while its physical acceptance remains ready-for-human; write that distinction in the issue rather than closing it.
