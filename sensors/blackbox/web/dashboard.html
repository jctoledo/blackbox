Phone setup

Set up while parked. Rotation changes the layout without stopping recording.

Android

Tap Full screen to hide browser controls. Use Back or Exit full screen to leave. A Home Screen shortcut to the device’s HTTP address may still open with browser controls.

iPhone

In Safari, choose Share → Add to Home Screen. Enable Open as Web App if offered and tap Add. Open that icon on Blackbox Wi-Fi. Turn off portrait orientation lock for landscape.

Keep your saved data

Download a full backup before switching browsers or Home Screen launch. Storage may be separate. If data is missing, restore the backup there as copies. Keep the same device address.

Stay on Blackbox Wi-Fi. Home Screen setup does not provide offline telemetry or guarantee background recording.

Align sensor to car

Teach Blackbox which way the car faces. If the sensor is mounted rotated left or right, this sets the direction used for acceleration, braking and left/right force readings.

  1. Secure the sensor nearly level. Park outdoors and wait for GPS.
  2. Tap Start alignment while parked.
  3. At a controlled site, drive forward, then brake steadily in a straight line. Leave the screen alone while moving.
  4. Park again. When a proposed alignment is ready, tap Use this alignment.

This does not align GPS or point the car north. Startup bias calibration is a separate stationary step. Do not collect this alignment while reversing.
